# Bundled fonts

These original font files ship with the application and load locally; font use never requires a network request.

- Libron 0.30: https://github.com/nicoverbruggen/libron/releases/tag/v0.30. Four TTF styles from Libron.zip. License: libron/OFL.txt (from tag v0.30).
- Barlow: https://github.com/google/fonts/tree/main/ofl/barlow. Regular, bold, italic and bold italic. License: barlow/OFL.txt.
- Noto Sans: https://github.com/google/fonts/tree/main/ofl/notosans. Variable regular and italic, weights 100–900. License: noto-sans/OFL.txt.

All three are licensed under the SIL Open Font License 1.1. Their copyright notices and licenses accompany the fonts in the installed app's bundled assets.
